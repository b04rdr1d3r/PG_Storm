A (rather) simple DCS template for the Persian Gulf map aimed at simulating a NATO/US centric action against Iran. 
Purpose is to maintain freedom of navigation in the Hormuz ztrait (cf operation Earnest Will in the 80s or the current events...)

uses MOOSE, MIST, CTLD and Skynet for the red side.
you can use all those functionalities to build ad hoc missions.

CSAR script is also loaded and available.
